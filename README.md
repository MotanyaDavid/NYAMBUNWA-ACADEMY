# Sunshine Schools Website

A modern, responsive marketing website for Nyambunwa Academy built with HTML, CSS, and vanilla JavaScript.

## Overview

Multi-page brochure website for a private co-educational day and boarding school in Kisii, Kenya. Features admissions, gallery, downloads, careers, and contact functionality.

## Pages

- **Home** - Hero section, welcome, features, programs, stats, testimonials, news
- **About Us** - History timeline, mission & vision, leadership team
- **Admissions** - Application process, fee structure, forms, FAQ
- **Gallery** - Photo gallery with filters, video gallery, school anthem
- **Downloads** - Admissions forms, academic calendars, policies, newsletters
- **Careers** - Current vacancies, application form
- **Contact Us** - Contact form, Google Maps, campus locations
- **Portals** - Student, parent, and staff login gateways

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- Font Awesome 6, Google Fonts
- Centralized data via school-data.js

## Setup

1. Clone the repository
2. Open `index.html` in a browser
3. To deploy, connect to Netlify or Vercel

## Customization

Edit `school-data.js` to update all school information across the entire website.
